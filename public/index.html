기준 이미지 8개의 512차원 벡터를 저장합니다. FP32 기본 DB 포함, Hailo는 장치에서 생성하세요.

이미지 DB 모드는 위 상대 점수 임계값을 사용하지 않습니다. 코사인 점수는 확률이 아니며, 기본 기준은 실제 촬영으로 교정해야 합니다.

CLIP: Mac Apple GPU(MPS) / Windows GPU(ONNX) / Hailo NPU(HEF). 모델과 실행 파일은 로컬에서 읽습니다. Siamese 학습은 현재 CPU, 추론은 GPU입니다. Hailo용 Siamese 컴파일은 미완료입니다.
